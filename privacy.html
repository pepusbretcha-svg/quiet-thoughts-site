Privacy policy

Quiet Thoughts publishing application · last updated 3 November 2026

Quiet Thoughts is a personal program that uploads short videos to its own YouTube channel through the official YouTube Data API v3. It runs on a single private computer and is not distributed to anyone.

What it accesses

The application requests one Google permission:

  • https://www.googleapis.com/auth/youtube.upload — permission to upload videos to the YouTube channel owned by the person who authorises it.

It requests no other scope. It cannot read, edit or delete existing videos, cannot read comments, analytics, subscriber data or playlists, and cannot access Gmail, Drive, Contacts, Calendar or any other Google service.

What it stores

After authorisation, Google issues an access token and a refresh token. These are written to a single file on the computer that runs the program and are used only to upload videos to the authorised channel. They are never transmitted anywhere except to Google's own servers, and the program removes anything resembling a credential from its logs before writing them.

The application stores no personal data about anyone. It keeps no database of users, collects no analytics, sets no cookies and has no server component. This website is static and does not track visitors.

What it shares

Nothing. No data obtained through Google APIs is sold, shared, transferred or disclosed to any third party, for any purpose, including advertising, profiling, credit assessment or model training.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Tokens are kept only while the channel is being published to. Deleting the token file on the computer ends the program's access immediately. Access can also be revoked at any time, independently of the program, at myaccount.google.com/permissions.
